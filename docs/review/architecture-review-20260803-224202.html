  • • 测试打 StreamEvent，不拼 SSE 文本

7. Close remaining auth / abuse seams

Worth exploring security
  • api/agent.py — _agent_rate_key 只读 Cookie，鉴权认 Bearer
  • api/auth.py — JSON body 仍返回 access/refresh
  • schemas/project.py — ProjectCreate.url 无 github/https 白名单
  • archive/data/stash_users.json — password_hash+salt 已入库
  • 无 .github/workflows · 无 .env.example · 无 CSRF token

已核实优点

  • SECRET_KEY ≥32 强制
  • Fernet at-rest（LLM key / PAT）
  • Refresh 哈希轮换 + family revoke
  • LLM SSRF + DNS 二次校验
  • Agent message max_length + 20/min 限流（9bd682c）
  • FE Mermaid DOMPurify + Markdown sanitize
  • Real 路径 httpOnly Cookie

仍开放

  • 限流 key ≠ 鉴权路径（Bearer→IP）
  • body token 抵消 Cookie XSS 收益
  • debug 默认 SameSite=None
  • 无 CI 门禁
  • VITE_USE_MOCK 默认开（误配静默）
  • archive 凭证材料应移出或 scrub
